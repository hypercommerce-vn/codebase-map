CBM Mod + Claude Replay

Biến Codebase Map thành mod gắn liền với Claude: thanh trạng thái always-on, pane 3-tab cạnh chat, và tính năng Claude Replay để tua lại từng bước Claude đã làm trên dự án — đồng bộ với graph codebase.

⚡ Status: Chờ CEO duyệt design

1Tổng quan & Mục tiêu

Mod là lớp vỏ gắn CBM vào ngay giao diện Claude: anh không cần mở browser rời để xem board/graph, cũng không cần ngồi đọc lại transcript để biết Claude đã làm gì trên dự án — tất cả ở trong cùng 1 cửa sổ.

User Story

"Là CEO không rành code, tôi muốn vừa chat với Claude vừa thấy luôn Claude đang sửa phần nào của dự án (trên graph), và sau đó tua lại từng bước nó đã làm — để tôi hiểu (hoặc cho dev khác xem) mà không phải đọc code."

5Claude Replay — trọng tâm

Tính năng mới. Tua lại từng bước Claude đã làm trên dự án — như Google Doc version history, nhưng thấy luôn context chat, tool call, và file nào bị động trên graph codebase.

5.1 — Cấu trúc 1 step

Mỗi step trong replay gộp 3 loại event từ JSONL:

  • user — prompt từ anh
  • assistant — câu trả lời của Claude
  • tools-used — mỗi tool call (Write, Edit, Bash...)
  • file-history-delta — file nào thay đổi ở step này (data chính sync graph)

5.4 — Phân biệt với git log

Git log cho thấy:
  • Commit hash + diff
  • Message (thường ngắn)
  • File thay đổi (list)
Claude Replay cho thêm:
  • Context chat: tại sao Claude làm vậy
  • Từng tool call riêng (git chỉ thấy commit kết)
  • Timing: Claude mất bao lâu, có bị user interrupt không
  • Sync graph: file bị động = node highlight
  • Resume context: click "Continue here" mở session tiếp

7Acceptance Criteria

  • AC-1 — Status line hiện trong Claude Code với 6 slot: Sprint · Branch · PR · CI · Snapshot · Risk. Mỗi slot refresh đúng nguồn (bảng mục 3).
  • AC-2 — Mở pane cạnh chat qua lệnh /cbm-mod open. Pane có 3 tabs hoạt động (Graph · Timeline · Replay).
  • AC-3 — Tab Graph render được graph.json của repo hiện tại, zoom/pan OK. Click node → sendPrompt về chat ("/cbm-impact <node>").
  • AC-4 — Tab Timeline list snapshots từ codebase_map snapshot list. Click snapshot → diff với current.
  • AC-5 — Tab Claude Replay list sessions từ ~/.claude/projects/<encoded-path>/*.jsonl. Chọn session → player hiện step-by-step.
  • AC-6 — Replay player có nút ⏮ ⏪ ▶ ⏩ ⏭ và scrubber. Hiện đúng user/claude/tool/file-delta.
  • AC-7 — Replay sync Graph tab: step hiện tại touch file X → node X highlight vàng.
  • AC-8 — Hook pre-commit tự động chạy codebase-map snapshot create --label pre-commit-$SHA.
  • AC-9 — Toast hiện khi: commit mới (✅) · CI fail (❌) · snapshot regenerated (📊). Click → mở tab tương ứng.
  • AC-10 — Pane load < 1s trên repo CBM (173 tests, 60+ files). Replay 1 session 100 step < 2s.
  • AC-11 — Mod không collect data ra ngoài máy. Status line không gọi mạng ngoài gh cli (đã auth local).
  • AC-12 — Cài đặt qua pipx install codebase-map + 1 lệnh cbm-mod install (symlink vào ~/.claude/plugins/).
